# JARVIS — агентлар учун қоидалар

Бу папка (`jarvis/`) — мустақил дастур. Репозиторий илдизидаги Next.js лойиҳаси (KPI AUDIT PRO) билан боғлиқ эмас; унинг файлларига тегманг.

## Стек
Node 20+ · TypeScript (tsx билан, build йўқ) · Express 5 · better-sqlite3 (FTS5) · React 19 + Vite · pdfjs-dist · @anthropic-ai/sdk.
- `server/` — backend (`app.ts` маршрутлар, `db.ts`, `migrations/*.sql`, `ai.ts` провайдерлар, `docs.ts` ҳужжатлар/қидирув, `memory.ts`, `chat.ts`, `workflows.ts`, `tasks.ts` режалаштирувчи, `markdown.ts`, `vault.ts`, `backup.ts`, `seed.ts`).
- `web/src/` — интерфейс (`pages/*`, `ui.tsx`, `i18n.ts` — кирилл матнлар, лотинга автоматик ўгирилади).
- `shared/translit.ts` — кирилл↔лотин.

## Буйруқлар
`npm test` · `npm run typecheck` · `npm run build` · `npm start` · `npm run dev`.
Ҳар ўзгаришдан кейин `npm run typecheck && npm test` ўтиши шарт.

## Қоидалар (PDF, 8-бет асосида)
- Файл ва маълумотларни рухсатсиз ўчирманг; муҳим файлни backup’сиз устидан ёзманг.
- Хавфли амалдан олдин нима ўзгаришини тушунтиринг. Кичик, қайтариладиган ўзгаришлар.
- UTF-8 ва ўзбек ҳарфларини (ў қ ғ ҳ, oʻ gʻ) сақланг.
- Схема ўзгариши — фақат янги `server/migrations/NNN_*.sql` файл (эскисини таҳрирламанг).
- AI таклифи ҳеч қачон автоматик «accepted» қарор бўлмайди; AI фактни «fact» сифатида сақламайди (`createNote(..., 'ai')`).
- API калитлари фақат серверда (шифрланган); жавобларда, логларда, тестларда очиқ кўринмасин.
- Mock натижани ҳақиқий AI деб кўрсатманг.
- Охирида: ўзгарган файллар, яратилган файллар, огоҳлантиришлар, кейинги қадам — `PROGRESS.md`ни янгиланг.
