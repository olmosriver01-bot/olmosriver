## Ўзим қўшган ечимлар (PDF’да йўқ)
Парол билан кириш; калитларни AES-256-GCM шифрлаш; харажат/лимит назорати; FTS5 қидирув (кирилл↔лотин); версиялар ва сават; кунлик backup ва тиклаш; vault зиддиятини аниқлаш; SSRF ҳимояси; кирилл/лотин интерфейс алмаштиргич.

## Тунги сессияда қўшилди
- Скан PDF учун маҳаллий OCR (Tesseract, интернетсиз; uzb, uzb_cyrl, rus, eng), фонда ишлайди, қайта ёқилганда давом этади, «OCR» белгиси.
- Чатда оқимли жавоб (SSE) — Anthropic, OpenAI, Gemini.
- Бош саҳифада PDF checklist (0→100) ва тезкор 00_INBOX ёзуви; калитсиз провайдерлар «Уланиш кутилмоқда».
- `install-macos.sh` — Mac ёқилганда JARVIS ўзи ишга тушади (LaunchAgent). macOS’да ҳали ишга туширилиб кўрилмаган (Linux’да синтаксис ва plist текширилди).
- Узилишдан кейин «running»да қолган жараён/ишлар тикланади (такрорий бажармасдан).
- Мустақил код-ревью 10 та хато топди — ҳаммаси тузатилди ва регрессия тести ёзилди: кунлик backup такрорланиши (Тошкент/UTC), URL редирект/DNS орқали SSRF, vault’да бир хил номли ёзувлар, ишлар давомида backup тиклаш, саватдаги лойиҳа, қайта ёқилган такрорий иш, саватдаги профил, кирувчи маълумот текшируви, бегона jarvis_id импорти, ўчирилган ҳужжат файли.

## 2026-11-26 сессияси (булут Linux; Mac уланмаган)
Linux’да ҳақиқий сервер жараёни билан, MOCK’сиз текширилди:
- GitHub’дан тоза клон → `npm ci` → `npm run build` → сервер `127.0.0.1:3333`да очилди.
- Синов базасида суҳбат яратилди, сервер тўхтатилиб қайта ёқилди — суҳбат ва хабарлар сақланган (браузерда десктоп ва iPhone ўлчамида ҳам).
- Калит йўқлиги учун AI жавоби ўрнига «уланиш кутилмоқда» хатоси сақланди (сохта жавоб йўқ).
- CLI backup → ёзувни ўзгартириш → CLI restore: асл матн (ўзбек ҳарфлари билан) қайтди; pre-restore нусхаси олинди.
- Уч марта ишга тушганда бир Тошкент кунига фақат битта автоматик backup.
- Синов пароли логларда ва журналда йўқ.
Тузатилди: install-macos.sh (PORT йўқлиги, TCC огоҳлантириши, launchctl print текшируви, 20 сония кутиш); maybeAutoBackup + тест; Anthropic fallback beta рад этилса қайта уриниш; «Текшириш»да модел автоматик танланиши; қўлда қўйилган суҳбат номи сақланади.
**Mac’да ҳали бажарилмаган:** install-macos.sh ишга тушириш, LaunchAgent рўйхатдан ўтиши, ҳақиқий API калити билан ўзбекча жавоб. Буйруқлар README’да.

## Ҳақиқий API билан ТЕКШИРИЛМАГАН
- Anthropic, OpenAI, Gemini — ҳақиқий калит бу муҳитда йўқ эди. So‘rov/javob форматлари расмий ҳужжат ва SDK асосида ёзилган, сохта сервер билан текширилган.
- OpenAI/Gemini сукут модел номлари (`gpt-6.2-astra`, `gemini-3.5-flash`) — ҳужжатлардан олинган, лекин манбалар бир-бирига зид эди. Калит киритгач «Текшириш» тугмаси билан тасдиқланг ва керак бўлса модел ID’ни ўзгартиринг.
- Ҳақиқий Obsidian иловаси билан текширилмаган (файл тизими даражасида тест қилинган).

## Очиқ масалалар / кейинги қадамлар
1. Ҳақиқий API калитлари билан учала провайдерни текшириш (Созламалар → «Калитни текшириш», кейин суҳбат).
2. OpenAI ва Gemini нархларини Созламалар → Харажат бўлимига киритиш.
3. OCR сифати паст сканларда AI vision орқали ўқиш (калит уланганда).
4. Семантик (embedding) қидирув — ҳозир BM25 калит сўз қидируви.
5. `install-macos.sh`ни ҳақиқий Mac’да синаш.
