# JARVIS RULES

@AGENTS.md

## General
- Do not delete files without explicit approval.
- Do not overwrite important files without creating a backup.
- Explain what you intend to change before destructive operations.
- Prefer small, reversible changes.
- Preserve UTF-8 and Uzbek characters.

## Obsidian
- Markdown only unless asked otherwise.
- Use the existing folder structure (00_INBOX … 10_ARCHIVE).
- Do not invent metadata. Keep existing notes intact.

## Output
- First show a short plan, then execute.
- At the end report: changed files, created files, warnings, next step. Update PROGRESS.md.
