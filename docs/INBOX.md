# Ёзишмалар назорати (Inbox) модули

Telegram Business ва Instagram профилларидаги мижоз ёзишмаларини бир ойнага йиғади, жавобсиз
мижозларни топади, масъулни белгилайди, AI ёрдамида сифат камчиликларини далил билан кўрсатади ва
раҳбарга Telegram орқали огоҳлантириш ҳамда кунлик ҳисобот юборади.

> Модул шу репозиторийдаги дастурнинг логини, роллари (ADMIN / MANAGER / EMPLOYEE) ва «компания = дўкон»
> ажратилиши устига қурилган. Gulzor CRMнинг буюртмалар базасига уланмаган: суҳбатга буюртма **рақами**
> қўлда боғланади, нарх ва мавжуд гуллар эса созламалардаги «тасдиқланган рўйхат»дан олинади.

## Муҳит ўзгарувчилари

| Ўзгарувчи | Вазифаси |
|---|---|
| `APP_URL` (ёки `NEXTAUTH_URL`) | Дастурнинг очиқ **HTTPS** манзили. Webhook ва Telegram тугмалари шу манзилни ишлатади. |
| `INBOX_ENCRYPTION_KEY` | Бот токени, Instagram токени ва app secret шу калит билан шифрланади (AES-256-GCM). Бўлмаса `NEXTAUTH_SECRET` ишлатилади. Калит ўзгарса сақланган токенлар ўқилмайди — профилларни қайта улаш керак бўлади. |
| `ANTHROPIC_API_KEY` | AI сифат текшируви учун. Бўлмаса қолган ҳамма нарса ишлайди, AI топилмалари пайдо бўлмайди. |
| `IG_GRAPH_VERSION` | Ихтиёрий, Instagram Graph API версияси (сукут бўйича `v24.0`). |
| `INBOX_CRON_SECRET` | Ихтиёрий: `POST /api/inbox/cron` ни ташқи cron орқали чақириш учун. |
| `INBOX_SCHEDULER=off` | Ихтиёрий: сервер ичидаги режалаштирувчини ўчириш. |

Fly.io: `fly secrets set APP_URL=https://<app>.fly.dev INBOX_ENCRYPTION_KEY="$(openssl rand -hex 32)" ANTHROPIC_API_KEY=...`

Эскалация, уланиш текшируви ва 23:00 ҳисоботи сервер ичидаги режалаштирувчида (`src/instrumentation.ts`,
ҳар дақиқада) ишлайди — шунинг учун камида битта машина доим ишлаб туриши керак (`fly.toml`:
`min_machines_running = 1`). Бир нечта машина бўлса ҳам такрорий хабар юборилмайди (базадаги ягона калитлар).

## Профилларни улаш

### Telegram (Business Bot)
1. @BotFather → `/newbot`, сўнг **Bot Settings → Business Mode → Turn on**.
2. CRM: Ёзишмалар назорати → Созламалар → «Telegram бот» → токенни киритинг (webhook автоматик ўрнатилади).
3. Дўкон аккаунтида (Telegram Premium керак): **Settings → Telegram Business → Chatbots** → бот номини
   киритинг, «Reply to messages» рухсатини беринг.
4. Профил созламалар саҳифасида ўзи пайдо бўлади. Битта аккаунтга фақат битта бот уланади; битта бот эса
   бир нечта аккаунтга хизмат қила олади (3 та Telegram профил учун битта бот етарли).

### Instagram (Instagram API with Instagram Login)
1. developers.facebook.com да илова яратинг, **Instagram** маҳсулотини қўшинг («API setup with Instagram login»).
2. CRM созламаларига Instagram App ID ва App Secret киритинг — саҳифада Webhook URL, Verify token ва
   OAuth Redirect URI пайдо бўлади; уларни Meta иловасига киритинг, webhook майдонларидан `messages`,
   `message_reactions`, `message_edit` ни ёқинг.
3. Instagram аккаунт Professional (Business/Creator) бўлиши ва иловада роли (тестер) бўлиши керак;
   Instagram иловасида «Allow access to messages» ёқилган бўлсин.
4. CRMда «Instagram профилни улаш» → Instagram ойнасида рухсат беринг.
5. Бегона аккаунтлар учун ва чекловсиз ишлаш учун: App Review (`instagram_business_manage_messages`),
   бизнес тасдиқлаш ва иловани **Live** режимга ўтказиш.

### Чекловлар (платформа қоидалари)
- Эски тарих: Telegram Business уланишдан олдинги хабарларни бермайди; Instagram ҳар суҳбатда охирги
  20 та хабар тафсилотини беради. Бу версияда тарих импорт қилинмайди — ҳар профилда «кузатув бошланган вақт» кўрсатилади.
- Мижознинг охирги хабаридан 24 соат ўтгач API орқали жавоб ёзиб бўлмайди.
- Иловадан тўғридан-тўғри ёзилган жавобда API ходимни билдирмайди → «муаллиф аниқланмаган».
