# KPI AUDIT PRO

KPI тизимининг етуклик даражасини баҳолаш, муаммоли соҳаларни аниқлаш, уларни вазифаларга айлантириш
ва вақт ўтиши билан ривожланишни кузатиш учун SaaS даражасидаги веб-дастур.

Манба: `KPI_Tizimi_Auditi.xlsx` файлидаги 7 блок / 42 мезон, баҳолаш шкаласи (0–3) ва барча ҳисоблаш
формулалари (`src/lib/kpi-data.ts`, `src/lib/scoring.ts`) openpyxl орқали формулалар даражасида
текшириб кўчирилган.

## Технологиялар

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 + қўлда қурилган shadcn-услубидаги UI компонентлар (Radix UI асосида)
- Prisma ORM. **Эслатма:** бу контейнерда PostgreSQL сервери мавжуд эмаслиги сабабли dev учун
  SQLite ишлатилган (`prisma/schema.prisma`). Ишлаб чиқаришга ўтишда фақат `datasource.provider`
  ни `"postgresql"` га ва `DATABASE_URL` ни ҳақиқий Postgres ulanish satriga алмаштиринг — схема
  ўзгармайди.
- NextAuth (Credentials) — ролларга асосланган авторизация (ADMIN / MANAGER / EMPLOYEE)
- Recharts, Lucide Icons, next-themes (light/dark)
- ExcelJS (Excel экспорт), Playwright + Chromium (PDF ҳисобот)

## Асосий имкониятлар

- Dashboard: умумий етуклик даражаси, балл/126, блоклар бўйича диаграмма, кучли/заиф йўналишлар, олдинги аудитга нисбатан фарқ
- 7 блок × 6 савол аудит ўтказиш: карточкали 0–3 балл танлаш, изоҳ, ҳужжат бириктириш, автоматик сақлаш, блок бўйича прогресс
- **Муҳим қоида:** жавобсиз савол 0 балл деб ҳисобланмайди; барча 42 саволга жавоб берилмагунча якуний фоиз/даража/ҳолат кўрсатилмайди (бу Excel файлнинг SUM(bo'sh=0) хулq-atvoridan ataylab chetga chiqilgan joy — pastga qarang)
- Натижа таҳлили: 0/1 балл олган мезонлар, устуворлик бўйича саралаш, блок тавсиялари, bottleneck
- Муаммони вазифага айлантириш: масъул, муддат, устуворлик, ҳолат (Янги → Режалаштирилган → Жараёнда → Текширувда → Бажарилган), far файл
- Аудит тарихи ва 2 та аудитни солиштириш (блок бўйича фарқ, бартараф этилган/ҳали заиф мезонлар)
- PDF ва Excel ҳисобот экспорти
- Кўп компания (мультитенант), компания маълумотлари изоляцияси, Admin панели (компаниялар, фойдаланувчилар, аъзолик)
- Ихтиёрий AI тавсия (фақат `ANTHROPIC_API_KEY` муҳит ўзгарувчиси созланганда ишлайди; бўлмаса ҳам дастур тўлиқ ишлайди)
